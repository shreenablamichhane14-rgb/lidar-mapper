You are a senior iOS engineer, AR/3D computer-vision engineer, CAD/geometry engineer, and product designer.

Your task is to design and build a professional-grade iPhone 3D mapping application that uses the iPhone’s LiDAR scanner, cameras, IMU, ARKit, RoomPlan where appropriate, and other native Apple frameworks.

The goal is to create a completely local, privacy-focused, easy-to-use alternative to premium LiDAR scanning and floor-plan applications.

The application must be usable by a complete amateur while still offering advanced functionality expected from professional paid mapping applications.

The application should support scanning:

* A single room
* Multiple connected rooms
* Entire houses/buildings
* Commercial spaces
* Restaurants
* Offices
* Warehouses
* Outdoor structures when technically possible
* Furniture
* Appliances
* Equipment
* Vehicles
* Boxes
* Small/medium physical objects
* Arbitrary physical objects where LiDAR/camera reconstruction is feasible

The application should use both LiDAR geometry and camera imagery whenever possible.

The final result should not only be a rough point cloud.

The user should be able to obtain:

1. A realistic textured 3D model
2. A high-detail LiDAR mesh
3. A clean architectural 3D model
4. A 2D floor plan
5. Measurements
6. Object dimensions
7. Room dimensions
8. Surface area
9. Floor area
10. Ceiling height
11. Distance measurements
12. Images/photos associated with scanned locations
13. Editable detected objects
14. Exportable professional files

==================================================
CORE DESIGN PRINCIPLE
=====================

The application must maintain multiple representations of the same scan whenever possible.

Representation A — RAW SCAN

Preserve the highest practical amount of sensor data, including:

* LiDAR mesh
* ARKit anchors
* camera poses
* camera frames where permitted
* depth information
* confidence information
* feature points
* detected planes
* world transforms
* timestamps
* device orientation
* calibration information where available

Never destroy the original raw scan when the user edits the project.

Representation B — REALISTIC MODEL

Generate a visually realistic 3D reconstruction using:

* LiDAR geometry
* RGB camera imagery
* texture projection
* photogrammetry techniques where appropriate
* mesh cleanup
* hole filling where mathematically reasonable
* texture blending
* mesh simplification for performance

Representation C — CLEAN MODEL

Generate a simplified CAD/architectural representation containing:

* walls
* floors
* ceilings
* doors
* windows
* openings
* stairs where detectable
* counters
* cabinets
* furniture
* appliances
* structural features
* other recognized objects

Representation D — 2D FLOOR PLAN

Automatically create a top-down floor plan from the reconstructed geometry.

Representation E — OBJECT MODEL

When scanning an individual object, generate an isolated 3D object rather than treating it as a room.

==================================================
IMAGE / TEXTURE CAPTURE
=======================

This is extremely important.

Where technically possible, use the iPhone camera to create realistic textures for the 3D geometry.

Do not simply create a gray LiDAR mesh.

Capture camera imagery and associate images with camera poses.

Use those images to texture the reconstructed mesh.

Handle:

* exposure differences
* lighting changes
* overlapping images
* perspective differences
* texture seams

Preserve original image quality where practical.

If a perfect texture reconstruction is not possible, produce the best available result while preserving geometry.

Provide modes such as:

PHOTO REALISTIC

TEXTURED

SOLID COLOR

WIREFRAME

RAW MESH
